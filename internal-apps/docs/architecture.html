Three lanes, one governed fleet

Analysts keep Power Apps forms + approvals. This repo is the Devin-built lane: four apps on shared platform packages, each with its own database, image, and rollback. Power BI reporting is replaced by refundlens over time.

Dashed amber = monorepo boundary. All ports distinct (8080–8083) because apps share the internal-apps namespace.

Per-app deploy units

  • • One OCI image, one Postgres, one version stream, one pipeline, one rollback — per app
  • • apps/<app>/deploy/ rendered from platform/packages/deploy/k8s (never hand-edited)
  • • Shared internal-apps namespace — distinct ports 8080–8083; track:stable + bluegreen cutover

Platform law

  • • apps → platform at build time only; import-lint rejects the reverse
  • • platform is never a runtime service — packages bake into each image
  • • No shared databases, no cross-app calls without an ADR

Data classification

  • • C4 (KYC PII): app-layer AES-256-GCM + KMS envelope — masked by default, audited reveal
  • • C3 commercial: plaintext ok, logged sparingly — no cardholder data ever
  • • Secrets via ${APP}-env from vault — names only in repo; C4 never in telemetry or fixtures
